# البنية التحتية للمكتبات الرقمية والبحث العلمي بالجامعة

**Proxmox VE · Ubuntu Server · SudanREN · Koha · DSpace**

![رسم هندسي توضيحي](../assets/university-infrastructure.svg)

## نبذة عن المشروع

تركيب خادم فعلي داخل الجامعة السودانية وتشغيل بيئة افتراضية باستخدام **Proxmox VE**، ثم تثبيت نظام **Ubuntu Server** على خادم افتراضي لاستضافة منصتَي **Koha** و**DSpace** للمكتبات الرقمية والمنشورات العلمية.

## الإنجازات الرئيسية

- تجهيز الخادم الجامعي وإعداد الافتراضية.
- ربط الخادم بعنوان عام عبر شبكة السودان للبحث والتعليم **SudanREN**.
- تثبيت Koha لإدارة الكتب وفهرستها وDSpace لنشر وحفظ المواد العلمية الرقمية.
- إتاحة الوصول للطلاب وأعضاء هيئة التدريس.
- إنشاء حسابات وصلاحيات للعاملين بالمكتبات لإضافة الكتب والمنشورات.
- إعداد المزامنة مع الخادم المركزي للجامعة ضمن بيئة وزارة التعليم العالي والبحث العلمي السودانية، بحسب وصف مهندس المشروع.

## مسؤولياتي

تركيب الخادم، وتهيئة Proxmox وUbuntu Server، وإعداد الاتصال الأكاديمي، ونشر التطبيقات وإدارة الحسابات والتكامل المؤسسي.

الرسم **تصوري وغير تنفيذي**؛ ولا يشمل عناوين IP حقيقية أو بيانات اعتماد أو إعدادات مزامنة خاصة.
